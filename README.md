# Pražský kompas 2026

Klikací hra k pražským komunálním volbám 9. a 10. 10. 2026: 20 výroků, pozice na mapě Prahy a „tvůj primátor". Fork [Českého kompasu](https://github.com/miloscermak/kompas).

- `web/`: hotový web (vanilla HTML/CSS/JS, bez buildu), návod na úpravy je v `web/README.md`
- `koncept.md`, `otazky.md`, `reserse.md`: koncept, otázky s kódováním a rešerše
- `predavaci-protokol.md`: stav projektu a postup nasazení

Nasazení na Netlify: base directory `web`, build command prázdný.
